# Pokémon UNITE 全技能組一勝挑戰 V6

完整網站專案，保留 V5 的角色名單、頭像資料、技能預填、搜尋、篩選、進度統計、自動保存與 JSON 備份。

## 本次規則更新
- 從閃電鳥（Zapdos）開始及之後推出的角色，設定為單一路線：每隻只計一勝。
- 火焰雞：單一勝利，因集結招式可切換踢擊／拳擊風格。
- 超級噴火龍 X、超級噴火龍 Y、超級路卡利歐、超級暴鯉龍：固定技能組，各計一勝。
- 夢幻：單一勝利。
- 武道熊師：一擊流與連擊流各自固定配對，各計一勝，不交叉混搭。
- 巨鉗螳螂：固定子彈拳，第二招選雙重攻擊或劍舞；各流派分開計勝，不與飛天螳螂路線混搭。
- 新增「固定流派」計算模式，可將每行視為一套完整配對，不會產生交叉組合。

## V5 資料遷移
首次載入會嘗試沿用 V5 localStorage 資料。對本次明確指定的角色會套用新規則並重設該角色的勝利勾選；其他角色的資料盡量保留。使用者尚未開始挑戰時，這樣可避免舊錯誤組合被沿用。

## 注意
技能名稱仍有部分為暫譯或預填參考，請依遊戲內現行版本自行核對。新的計算方式是依使用者提供的挑戰規則整理。
