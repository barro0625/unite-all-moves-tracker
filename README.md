# Pokémon UNITE 全技能組一勝挑戰 V8

## 本次更新
- 依照使用者提供的網站截圖，修補多個顯示文字替代圖示的寶可夢頭像網址，改用 PokeAPI 官方 artwork 圖片。
- 巨鉗螳螂改為 2×2 技能組，共四種：
  1. 雙翼＋劍舞
  2. 雙翼＋二連擊
  3. 子彈拳＋劍舞
  4. 子彈拳＋二連擊
- 保留 V7 其他角色名單、技能規則、搜尋、統計、自動保存與 JSON 匯入匯出。
- 首次載入 V8 會嘗試遷移 V7 瀏覽器資料；巨鉗螳螂會強制套用新的四組模式並清除舊有勝利勾選，其他紀錄盡量保留。
