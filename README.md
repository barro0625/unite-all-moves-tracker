# Pokémon UNITE 全技能組一勝挑戰 V12

## V12 更新內容
- 角色名稱搜尋：支援繁體中文與英文名稱。
- 新增五種角色定位篩選：攻擊型 28 隻、防禦型 13 隻、敏捷型 13 隻、平衡型 36 隻、輔助型 12 隻。
- 角色卡片背景及定位標籤依照定位使用不同顏色。
- 定位篩選可與挑戰進度篩選、名稱搜尋同時使用。
- 保留隨機挑戰、JSON 匯出／匯入、本機自動儲存。
- 完全移除 Supabase 雲端同步介面與程式碼。
- 首次開啟 V12 時會讀取 V11、V10 或 V9 瀏覽器紀錄，保留仍有效的技能組勝利紀錄。

## 五種定位顏色
- 攻擊型：紅色
- 防禦型：藍色
- 敏捷型：綠色
- 平衡型：紫色
- 輔助型：金色

## GitHub Pages 更新
將 `index.html`、`style.css`、`app.js`、`pokemon.json`、`README.md` 五個檔案上傳至 Repository 根目錄並覆蓋。Commit changes 後等待 GitHub Pages 更新，再使用 Ctrl+F5 強制重新整理。

## 備份提醒
紀錄儲存在目前瀏覽器的 localStorage。可使用「匯出備份」下載 JSON，並在其他瀏覽器或裝置使用「匯入備份」還原。

## 保留的遊戲規則
- 保留 102 隻角色、技能名稱、技能組模式、頭像與特殊規則。
- 保留大竺葵與阿羅拉雷丘頭像／名稱修正。
- 自動組合、單一勝利、固定流派三種計算模式維持不變。
- 隨機挑戰只會抽選已設定且尚未取得勝利的技能組。
